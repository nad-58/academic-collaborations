# Content Rights and Attribution

This repository contains public-facing summaries of academic–industry collaboration, postgraduate supervision, conference dissemination, and research outputs.

## Ownership and permission

Material should only be included when the contributor has permission to share it publicly. This may include personally authored text, jointly developed project summaries, approved poster content, original diagrams, public publication metadata, and other collaboration material cleared for reuse.

## Institutional names and logos

Institutional names may be used for factual attribution. Logos, branding assets, and visual identity material should only be included when reuse is permitted. This repository currently avoids embedding institutional logos in order to keep the portfolio neutral and reusable.

## Publications

Publication titles, author lists, abstracts written in original words, DOI links, and short public summaries may be included. Publisher-formatted PDFs or extensive copied text should not be uploaded unless the licence explicitly permits it.

## Student and collaborator attribution

Student and collaborator contributions should be represented accurately. Personal contact details, assessment records, unpublished student work, and confidential project information must not be included without explicit permission.

## Code and diagrams

Original code and diagrams created specifically for this repository may be reused with attribution unless a file states otherwise. Jointly authored or institution-owned material retains its original ownership.

## Corrections

If any collaborator believes that attribution, wording, or reuse permissions should be corrected, the relevant content should be reviewed and updated promptly.

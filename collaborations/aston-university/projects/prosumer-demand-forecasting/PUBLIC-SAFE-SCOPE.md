# Public-Safe Scope

This project is an anonymised educational reconstruction.

The repository includes:

- synthetic electricity-demand data;
- independently written Python code;
- general forecasting methodology;
- public-safe technical documentation;
- automated tests and examples.

The repository excludes:

- personal names and contact details;
- organisation and employer identities;
- signatures and assessment declarations;
- private datasets;
- original confidential figures or slides;
- unpublished model artefacts;
- restricted thesis content.

The public code demonstrates the methodology and does not claim to reproduce confidential experimental results exactly.

# Contributing

This repository documents academic–industry collaboration and supervision activities. Contributions should preserve accurate attribution, protect confidential information, and distinguish clearly between personal, student, institutional, and jointly authored work.

## Before adding content

Check that:

- the material is suitable for public sharing;
- collaborators and students are represented accurately;
- unpublished or confidential material is excluded;
- personal data is removed unless explicit permission exists;
- figures, posters, photographs, and publication excerpts can be reused;
- project outcomes are not overstated.

## Recommended project-page structure

Each project page should include:

1. Project title and overview
2. Institution and collaboration context
3. Technical problem
4. Methodology
5. Evaluation or experimental approach
6. Main outcomes
7. Individual contribution
8. Publication or conference output
9. Limitations and next steps
10. Public-content note

## Style

Use clear technical language, avoid confidential detail, and link to official publications where available. Do not copy large sections from publisher-owned papers.
